# Звук уведомлений

`public/assets/sounds/icq-uh-oh.mp3` — запись классического ICQ «Uh-oh».

- Источник записи: https://www.myinstants.com/media/sounds/icq-uh-oh.mp3
- Найден на сайте-посвящении ICQ: https://uhoh.im/ (элемент `audio#uhohsnd`).
- Скачан 10 ноября 2026 года, без преобразования или синтеза.
- SHA-256: `46ef2a3fc7a28bf186a4d0c0a9fe94fd6da71cd0810946106e94858df7a6c9ce`.
- Исторический звук ICQ / Mirabilis; файл не является собственной записью проекта.

Файл раздаётся самим приложением, внешних запросов при воспроизведении нет. Браузер декодирует MP3 через Web Audio, затем использует буфер для новых уведомлений и прослушивания при включении звука.

Громкость воспроизведения — 42% от исходной (`GainNode.gain = 0.42`), включая прослушивание в меню. По умолчанию звук включён. Адресация отделу учитывает всех его текущих участников; счётчик и звук появляются у каждого получателя, кроме самого отправителя, при получении нового непрочитанного обращения. Звук требует разрешённого браузером воспроизведения после пользовательского действия и следует существующему опросу доски.

Если включён Web Push и браузер разрешил аудио открытой вкладке, она воспроизводит ICQ-звук при событии push, а системное уведомление показывается без второго звука. До первого действия на странице после загрузки или при закрытых вкладках звучание системного уведомления определяет браузер и ОС: воспроизвести файл ICQ в фоне надёжным способом нельзя. Подробности настройки push — в корневом README.
