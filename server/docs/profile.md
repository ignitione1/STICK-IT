# Профиль

В «Моём профиле» сотрудник выбирает один из шести мужских или шести женских рисованных аватаров либо загружает своё фото. Переключатель «Мужчина / Женщина» фильтрует коллекцию, отдельное поле пола в учётной записи не создаётся.

Фото: JPG, PNG или WebP до 10 МБ. Браузер обрезает его по центру до квадрата и преобразует в JPEG 256 × 256, без метаданных исходного файла. Сервер принимает только JPEG data URL до 128 КиБ с размерами до 512 × 512; лимит JSON-запроса — 180000 байт. Фото хранится в `employees.avatar_photo` и выдаётся через защищённый `GET /api/profile/avatar/:id` с `Cache-Control: no-store` и `X-Content-Type-Options: nosniff`. JSON-ответы содержат только ссылку. При выборе готового аватара загруженное фото удаляется из записи.

Десять комплектов бумаги: «Тёплая классика», «Ботаника», «Розовое письмо», «Небесный», «Бумажный архив», «Космос», «Хороший день», «Морской бриз», «Тихое утро», «Цветочная почта». Кремовый «Бумажный архив» оставлен без рисунков. Остальные варианты дополнены полупрозрачными SVG-узорами: звёзды, листья, сердца, облака, планеты, улыбки, волны, кофе и цветы. Рисунки декоративные, не перехватывают мышь и не участвуют в доступном тексте. Варианты показываются без видимых подписей; названия доступны в подсказках и экранным дикторам.

Четыре независимых крепления: кнопка, скрепка, розовый скотч, матовая бумажная лента. Живой предпросмотр показывает аватар, бумагу и крепление. Изменение цвета не сбрасывает крепление. У ответов сохраняется соединяющая цепочку лента.

`PATCH /api/profile` принимает `paperStyle`, необязательные `fastening`, `avatarId` или `avatarPhoto` (аватар и фото вместе запрещены). Отсутствующие поля аватара/крепления сохраняют текущие значения. Доступны только собственные настройки; имя, логин, пароль, роль и отделы по-прежнему управляются администратором. Сохраняются проверки сессии, Origin и CSRF.

Оформление записки фиксируется при создании в `stickers.paper_style` и `stickers.fastening`; дальнейшие изменения профиля не меняют эти поля. Аватар автора отображается актуальный. Миграция `0003_crazy_puff_adder.sql` расширяет enum бумаги и добавляет крепления, сохраняя прежнее соответствие для существующих сотрудников и записок. `0004_nice_vance_astro.sql` добавляет хранение фото. Старые миграции не изменялись.

На локальном стенде новые миграции применяются командой `npm.cmd run dev:local` к выделенной базе `.local/manual/postgres`. В обычной PostgreSQL миграции применяются отдельно, только к известной настроенной базе.

Визуальный ориентир — [фоновые значки Telegram Premium](https://telegram.org/blog/reply-revolution). Узоры и аватары реализованы локальными SVG; ресурсы Telegram не копировались. Формы узоров используют установленный Lucide, аватары нарисованы для проекта.
