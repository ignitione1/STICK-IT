# Stick-it

**Stick it. Share it. Done.**

Stick-it — командная доска записок для отделов. Сотрудники оставляют стикеры, отвечают друг другу и следят за обращениями; администраторы управляют составом команды. Интерфейс доступен на компьютерах и мобильных устройствах.

## Возможности

- Общая доска и доски отделов, свободное расположение стикеров и цепочки ответов.
- Адресация сотруднику или отделу, отметки «Прочитано» и «Готово», поиск и фильтры.
- Архив со стопками по доскам, фильтрами и восстановлением записок.
- Вложения: до пяти файлов на записку, до 10 МиБ на файл и до 25 МиБ суммарно. Изображения можно просмотреть, документы — скачать.
- Профиль с готовыми аватарами или своим фото, десятью дизайнами бумаги и выбором крепления. Оформление применяется к новым стикерам.
- Счётчик непрочитанных, звук ICQ и push-уведомления на рабочем столе с отдельными переключателями.
- Два первоначальных администратора создаются отдельной командой; они добавляют отделы и учётные записи сотрудников.

Текст, вложения и архивирование записки доступны для изменения её автору. Отметки «Прочитано» и «Готово» общие для записки, а не отдельные для каждого получателя. Обновления доски поступают через периодический опрос сервера; после разрешения в браузере доступны и push-уведомления.

## Технологии

React, TypeScript, Vite, Fastify, PostgreSQL и Drizzle ORM. Для локального стенда и тестов используется PGlite — устанавливать PostgreSQL или Docker для первого запуска не требуется.

## Быстрый локальный запуск

Требуется Node.js 22.12 или новее. Из корня проекта:

```sh
npm ci
npm --prefix server ci
npm run dev:local
```

Откройте **http://127.0.0.1:5175**. При первом запуске создаются два локальных администратора `admin1` и `admin2` со случайными паролями. Пароли находятся в `.local/manual/local-admins.env`: откройте файл в редакторе и не публикуйте его. После входа создайте отделы и сотрудников в разделе «Управление командой». Для создания записок администратору тоже необходимо назначить активный отдел.

Локальная база и загруженные файлы сохраняются в `.local/manual/`; они переживают перезапуск. Для остановки нажмите Ctrl+C в терминале. Стенд использует порты 5175 и 3102 и не переносит данные на сервер автоматически. Существующие `.env` он не читает и не меняет. Изменение пароля в файле после создания администратора не меняет пароль в базе.

В PowerShell, если запуск `npm.ps1` запрещён политикой системы, замените `npm` на `npm.cmd` в командах.

## Push-уведомления на компьютере

В боковом меню под настройкой звука нажмите «Push выключены» и разрешите уведомления браузеру. Разрешение требуется на каждом устройстве. Локальный стенд создаёт ключи автоматически и хранит их в `.local/manual/push-keys.json`.

Для отдельного сервера сгенерируйте ключи командой `npm --prefix server run push:keys` и перенесите значения из созданного `.local/push-vapid.env` в защищённые переменные `VAPID_PUBLIC_KEY` и `VAPID_PRIVATE_KEY` файла окружения. Ключи должны оставаться постоянными между перезапусками; после смены ключей пользователям придётся переподключить подписки. Примените миграции вручную перед запуском сервера. Для реального сервера необходим HTTPS; localhost подходит для разработки. Серверу нужен исходящий доступ к push-службам браузеров.

При открытой вкладке проигрывается локальный звук ICQ, если браузер разрешил аудио после действия пользователя; системный звук при этом отключён. Пока аудио вкладки заблокировано или вкладок нет, браузер использует звук системного уведомления, поскольку надёжно воспроизвести MP3 приложения в фоне нельзя. Оповещения зависят от браузера, разрешений, сети и действующей сессии; отдельной очереди повторной доставки нет. Отключение звука сохраняется для данного аккаунта в браузере.

## Разработка с PostgreSQL

Создайте отдельную базу, настройте `server/.env` по примеру `server/.env.example`, примените миграции и создайте двух администраторов. Не заменяйте существующий `.env` и не публикуйте его. Пошаговая инструкция и параметры входа — в [документации сервера](server/README.md) и [описании учётных записей](server/docs/accounts.md).

Затем запустите API и интерфейс в отдельных терминалах:

```sh
npm --prefix server run dev
npm run dev
```

Vite обычно доступен на `http://127.0.0.1:5173` и проксирует `/api` на порт 3000. Для локального HTTP укажите соответствующий `APP_ORIGIN` и `COOKIE_SECURE=false`; для HTTPS требуется `COOKIE_SECURE=true`.

## Проверки

```sh
npm run build
npm --prefix server run typecheck
npm --prefix server test
npm run test:e2e
```

Браузерные тесты требуют установленный Microsoft Edge и используют изолированные API и PGlite на портах 3101 и 5174; данные ручного стенда не затрагиваются. Текущая конфигурация Playwright рассчитана на Windows и вызывает `npm.cmd`.

## Развёртывание

В [инструкции по развёртыванию](deploy/README.md) описан тестовый VPS с Docker Compose, доступом через SSH-туннель, ручными миграциями и резервным копированием. Это закрытый тестовый стенд, а не готовая инструкция для публикации в интернет. Базу и каталог вложений необходимо резервировать вместе; перед рабочим запуском отдельно проверьте контейнеры, постоянную PostgreSQL и восстановление резервной копии.

## Устройство проекта

- `src/` — интерфейс, состояние доски, профиль и архив.
- `server/` — Fastify API, схема базы, миграции и серверные тесты.
- `tests/` — браузерные сценарии Playwright.
- `deploy/` — настройки контейнеров и инструкции для VPS.
- `docs/` — сведения о материалах интерфейса и звуке уведомления.

Дополнительная документация: [общая доска](server/docs/shared-board.md), [вложения](server/docs/attachments.md), [профиль](server/docs/profile.md), [push-уведомления](server/docs/push.md), [звук уведомления](docs/notification-sound.md).

## Ресурсы и лицензия

Звук уведомления — сторонняя запись классического ICQ; источник указан в [описании звука](docs/notification-sound.md). Права на распространение звука и старых фотографий из исходного макета необходимо проверить отдельно перед публичной публикацией. Лицензия на исходный код проекта пока не выбрана; отсутствие файла LICENSE не означает разрешение на свободное использование.
